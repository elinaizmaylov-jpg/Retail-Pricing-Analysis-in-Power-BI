# Retail-Pricing-Analysis-in-Power-BI
This academic project focuses on analysing retail pricing data using Microsoft Power BI. The project explores how data modelling and visualisation can support the analysis of pricing information and business performance.
# Tools and Technologies
Microsoft Power BI
Star Schema Data Modelling
Data Visualisation
Business Intelligence
•	Transformed raw retail pricing data into a star-schema data model with fact and dimension tables to enable efficient, flexible reporting.
•	Identified main KPIs – total revenue, total profit and profit margin in %
•	Built an interactive Power BI dashboard with filters and visuals to compare prices across products, categories and time periods.
# Key Findings
Translated dashboard outputs into clear observations on pricing patterns, demonstrating how BI tools support business decisions. Finishing with relevant pricing strategy suggestions.
